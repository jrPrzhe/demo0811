## 🚀 Деплой на GitHub Pages

### Вариант 1: Через веб-интерфейс GitHub

1. Создайте новый репозиторий на GitHub (или используйте существующий)
2. Загрузите все файлы из папки `deploy-demo` в корень репозитория
3. Перейдите в Settings → Pages
4. Выберите источник: "Deploy from a branch"
5. Выберите ветку: `main` (или `master`)
6. Выберите папку: `/ (root)`
7. Нажмите Save
8. Демо будет доступно по адресу: `https://[ваш-username].github.io/[название-репозитория]/`

### Вариант 2: Через Git командную строку

```bash
# Клонируйте репозиторий
git clone https://github.com/jrPrzhe/demo0811.git
cd demo0811

# Скопируйте файлы из deploy-demo в корень репозитория
# (все файлы должны быть в корне, не в подпапке)

# Добавьте файлы
git add .
git commit -m "Add demo page"
git push origin main

# Включите GitHub Pages в настройках репозитория
```

## 📝 Важные замечания

- Все файлы должны быть в корне репозитория (не в подпапке)
- Изображения должны быть в папке `images/`
- Главный файл должен называться `index.html`

## 🎨 Функции демонстрации

- ✅ Темная тема в стиле Telegram Mini App
- ✅ Анимированный ассистент с разными эмоциями
- ✅ Автоматический тур по всем модулям
- ✅ Интерактивная навигация
- ✅ Адаптивный дизайн для мобильных устройств

## 📱 Модули

1. **Дашборд** - обзор финансов
2. **Счета** - управление счетами
3. **Транзакции** - история операций
4. **Категории** - организация расходов
5. **Цели** - финансовые цели
6. **Отчёты** - аналитика
7. **Совместные бюджеты** - общие финансы
