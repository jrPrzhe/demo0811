# 🚀 Инструкция по деплою на GitHub Pages

## Быстрый старт

### Шаг 1: Подготовка репозитория

```bash
# Клонируйте репозиторий
git clone https://github.com/jrPrzhe/demo0811.git
cd demo0811
```

### Шаг 2: Копирование файлов

Скопируйте все файлы из папки `deploy-demo` в корень репозитория:

**Структура должна быть:**
```
demo0811/
├── index.html
├── images/
│   ├── 1.png
│   ├── 2.png
│   ├── 3.png
│   ├── 4.png
│   └── 5.png
└── README.md
```

### Шаг 3: Коммит и пуш

```bash
# Добавьте все файлы
git add .

# Создайте коммит
git commit -m "Add Finance Manager demo page"

# Отправьте в репозиторий
git push origin main
```

### Шаг 4: Включение GitHub Pages

1. Перейдите на GitHub в ваш репозиторий: https://github.com/jrPrzhe/demo0811
2. Нажмите **Settings** (в верхнем меню)
3. В левом меню выберите **Pages**
4. В разделе **Source** выберите:
   - Branch: `main` (или `master`)
   - Folder: `/ (root)`
5. Нажмите **Save**

### Шаг 5: Готово! 🎉

Через несколько минут ваша демонстрация будет доступна по адресу:
**https://jrprzhe.github.io/demo0811/**

## Альтернативный способ (через веб-интерфейс)

1. Откройте репозиторий на GitHub
2. Нажмите **Add file** → **Upload files**
3. Перетащите все файлы из папки `deploy-demo`:
   - `index.html`
   - Папку `images/` со всеми PNG файлами
4. Нажмите **Commit changes**
5. Включите GitHub Pages (см. Шаг 4 выше)

## Проверка

После деплоя откройте ссылку и проверьте:
- ✅ Страница загружается
- ✅ Темная тема работает
- ✅ Ассистент отображается и меняет эмоции
- ✅ Все модули переключаются
- ✅ Навигация работает

## Обновление

Для обновления демо:
1. Внесите изменения в файлы
2. Выполните:
   ```bash
   git add .
   git commit -m "Update demo"
   git push origin main
   ```
3. Изменения появятся через 1-2 минуты
